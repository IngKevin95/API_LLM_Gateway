# HU-058: Debuguear y fijar handler Anthropic /v1/messages

## Resumen
Endpoint `/v1/messages` devuelve HTTP 400. Investigar validación y mapeo de request/response.

## Acceptance Criteria

```gherkin
Given: POST /v1/messages {"model":"claude-opus-4","messages":[{"role":"user","content":"test"}],"max_tokens":100}
When: envío request válido
Then: HTTP 200
And: response.content[0].text es string no vacío
And: response.stop_reason es "end_turn" o similar

And: si messages vacío: HTTP 400
And: si model no existe: HTTP 400
And: si provider error: HTTP 503
```

## Implementación

### Archivo: src/internal/api/anthropic/handler.go

1. **Añadir logging:**
```go
func (h *Handler) HandleMessages(w http.ResponseWriter, r *http.Request) {
	var req MessagesRequest
	if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
		log.Printf("HandleMessages: JSON decode error: %v", err)
		http.Error(w, ..., http.StatusBadRequest)
		return
	}

	log.Printf("HandleMessages: model=%s, messages=%d", req.Model, len(req.Messages))
	// ... resto
}
```

2. **Validación:**
- Revisar que messages es requerido
- Revisar que modelo es válido
- Revisar mapeo de role/content

3. **Response mapping:**
- Asegurar que response.content está siendo parseado
- Validar structure de respuesta Anthropic
