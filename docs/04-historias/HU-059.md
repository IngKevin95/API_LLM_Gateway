# HU-059: Implementar logging estructurado en todos los handlers

## Resumen
Añadir logging JSON estructurado en todos los handlers para facilitar debugging y monitoring.

## Acceptance Criteria

```gherkin
Given: Handler instrumentado con logs
When: procesamos request
Then: cada log contiene:
  - timestamp (RFC3339)
  - level (info, error, warn)
  - handler (openai, anthropic, etc)
  - method (chat, embeddings, messages)
  - model (nombre del modelo)
  - provider (proveedor elegido)
  - latency_ms (tiempo de ejecución)
  - status (200, 400, 500, etc)

And: si hay error:
  - error_type (provider, timeout, validation, etc)
  - error_message (descripción)
  - stack_trace (si aplicable)

And: logs NO contienen:
  - prompts (PII)
  - respuestas completas (PII)
  - API keys
```

## Implementación

### Crear logger helper: src/internal/log/logger.go

```go
package log

import (
	"encoding/json"
	"fmt"
	"log"
)

type LogEvent struct {
	Timestamp  string `json:"timestamp"`
	Level      string `json:"level"`
	Handler    string `json:"handler"`
	Method     string `json:"method"`
	Model      string `json:"model"`
	Provider   string `json:"provider,omitempty"`
	LatencyMs  int64  `json:"latency_ms,omitempty"`
	Status     int    `json:"status,omitempty"`
	ErrorType  string `json:"error_type,omitempty"`
	ErrorMsg   string `json:"error_msg,omitempty"`
	StackTrace string `json:"stack_trace,omitempty"`
}

func LogJSON(event LogEvent) {
	b, _ := json.Marshal(event)
	log.Println(string(b))
}
```

### Uso en handlers

```go
// openai/handler.go
start := time.Now()
log.LogJSON(log.LogEvent{
	Timestamp: time.Now().Format(time.RFC3339),
	Level:     "info",
	Handler:   "openai",
	Method:    "chat",
	Model:     req.Model,
	Status:    200,
	LatencyMs: time.Since(start).Milliseconds(),
})
```
