# HU-057: Implementar GatewayProcessor.ProcessEmbedding()

## Resumen
Endpoint `/v1/embeddings` está registrado pero ProcessEmbedding devuelve 501 "not implemented". Implementar usando failover engine.

## Acceptance Criteria

```gherkin
Given: POST /v1/embeddings {"model":"text-embedding-3-small","input":"test"}
When: envío request válido
Then: HTTP 200
And: response.data es array de EmbeddingData
And: cada elemento tiene vector (array de floats)
And: response.usage.total_tokens > 0

And: error handling:
  - Si model no soporta embeddings: HTTP 400
  - Si input vacío: HTTP 400
  - Si provider no disponible: HTTP 503
```

## Implementación

### Archivo: src/cmd/gateway/processor.go

Reemplazar ProcessEmbedding():
```go
func (gp *GatewayProcessor) ProcessEmbedding(ctx context.Context, req *adapter.Request) (*adapter.Embedding, error) {
	log.Printf("ProcessEmbedding: model=%s, inputs=%d", req.Model, len(req.Input))

	// Use "embedding" as capability (no streaming for embeddings)
	emb, err := gp.failover.Embed(ctx, "embedding", *req)
	if err != nil {
		log.Printf("ProcessEmbedding ERROR: %v", err)
		return nil, err
	}

	log.Printf("ProcessEmbedding OK: vectors=%d", len(emb.Vectors))
	return &emb, nil
}
```

### Cambios en failover.Engine
- Si no existe método `Embed()`, crear uno similar a `Complete()`
- Si existe pero no está implementado, implementar
