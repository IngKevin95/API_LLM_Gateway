# HU-054: Registrar adaptador OmniRoute en buildAdapters()

## Resumen
Tras crear el adaptador OmniRoute, registrarlo en buildAdapters() para que sea cargado al startup del Gateway.

## Acceptance Criteria

```gherkin
Given: Adaptador OmniRoute existe en internal/adapter/omniroute/
When: Gateway startup
Then: buildAdapters() incluye omniroute en adapters map
And: logs muestran "registry: X modelos cargados" incluyendo OmniRoute
And: no hay WARNING "sin adapter para proveedor omniroute"
```

## Implementación

### Archivo: src/cmd/gateway/main.go

**Agregar import:**
```go
import (
	adapteromniroute "api-llm-gateway/internal/adapter/omniroute"
)
```

**En función buildAdapters(), agregar:**
```go
// Add OmniRoute adapter (local provider, no API key needed)
adapters["omniroute"] = adapteromniroute.New("http://omniroute:20128/v1", "")
```

### Ubicación exacta
Después de la línea que registra local Ollama:
```go
// Add local Ollama if available (no API key needed)
adapters["local"] = adapterlocal.New("http://localhost:11434")

// Agregar AQUI:
// Add OmniRoute adapter (local provider, no API key needed)
adapters["omniroute"] = adapteromniroute.New("http://omniroute:20128/v1", "")

return adapters
```

## Testing

### Manual
```bash
# Reiniciar Gateway
docker-compose down && docker-compose up -d && sleep 3

# Ver logs
docker logs api-llm-gateway | grep "registry"
# Esperado: "registry: X modelos cargados" con OmniRoute incluido

# Ver que no hay warning
docker logs api-llm-gateway | grep "sin adapter para proveedor omniroute"
# Esperado: sin salida (sin warning)
```

### Criterio Pase
- ✓ Adaptador registrado
- ✓ Sin warnings de "sin adapter"
- ✓ Prueba: curl al Gateway usa OmniRoute

## Notas
- OmniRoute no requiere API key (pasamos "")
- La conexión es http://omniroute:20128/v1 (DNS interno Docker)
- Si OmniRoute no está corriendo, el adapter se crea pero falla en uso
