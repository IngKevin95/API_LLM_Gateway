# HU-060: Implementar /metrics con datos reales de operación

## Resumen
Endpoint `/metrics` devuelve `{}`. Implementar métricas operacionales real-time (latencias, tokens, providers).

## Acceptance Criteria

```gherkin
Given: GET /metrics
When: request llega
Then: HTTP 200
And: response JSON contiene:
  {
    "uptime_seconds": 3600,
    "requests": {
      "total": 42,
      "by_handler": {"openai": 30, "anthropic": 12},
      "errors": 3
    },
    "providers": {
      "openai": {"available": true, "last_success": "2026-07-23T13:52:08Z"},
      "anthropic": {"available": true, "last_error": null},
      "omniroute": {"available": true, "circuit_breaker_open": false}
    },
    "latency": {
      "p50_ms": 450,
      "p95_ms": 1200,
      "p99_ms": 2100
    }
  }
```

## Implementación

### Crear metrics collector: src/internal/metrics/metrics.go

```go
package metrics

import (
	"sync"
	"time"
)

type Metrics struct {
	mu sync.RWMutex
	
	StartTime      time.Time
	TotalRequests  int64
	TotalErrors    int64
	RequestsByHandler map[string]int64
	Latencies      []int64  // milisegundos
	ProviderStatus map[string]ProviderMetric
}

type ProviderMetric struct {
	Available          bool
	LastSuccess        time.Time
	LastError          string
	CircuitBreakerOpen bool
	SuccessCount       int64
	ErrorCount         int64
}

func (m *Metrics) RecordRequest(handler string, latencyMs int64, err error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	
	m.TotalRequests++
	m.RequestsByHandler[handler]++
	m.Latencies = append(m.Latencies, latencyMs)
	
	if err != nil {
		m.TotalErrors++
	}
}

func (m *Metrics) ToJSON() map[string]interface{} {
	m.mu.RLock()
	defer m.mu.RUnlock()
	
	return map[string]interface{}{
		"uptime_seconds": int64(time.Since(m.StartTime).Seconds()),
		"requests": map[string]interface{}{
			"total": m.TotalRequests,
			"by_handler": m.RequestsByHandler,
			"errors": m.TotalErrors,
		},
		"latency": map[string]int64{
			"p50_ms": percentile(m.Latencies, 0.50),
			"p95_ms": percentile(m.Latencies, 0.95),
			"p99_ms": percentile(m.Latencies, 0.99),
		},
	}
}
```

### Registrar en main.go

```go
var metrics *Metrics

func init() {
	metrics = &Metrics{
		StartTime: time.Now(),
		RequestsByHandler: make(map[string]int64),
	}
}

// En handler:
mux.HandleFunc("/metrics", func(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(metrics.ToJSON())
})
```
