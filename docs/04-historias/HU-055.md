# HU-055: Test de conectividad OmniRoute → Gateway

## Resumen
Verificar end-to-end que el Gateway puede llamar a OmniRoute exitosamente.

## Acceptance Criteria

```gherkin
Given: Gateway con adaptador OmniRoute registrado
And: OmniRoute corriendo en docker (port 20128)
When: POST /v1/chat/completions {"model":"auto", "messages":[...]}
Then: HTTP 200
And: response.choices[0].message.content es string no vacío
And: logs muestran "chosen_provider=omniroute"
And: latencia < 2s
```

## Testing

### Script de test
```bash
#!/bin/bash
set -e

echo "=== Test OmniRoute Adapter ==="

# 1. Health check
echo "1. Gateway health..."
curl -s http://localhost:8080/health | grep -q "ok" && echo "✓" || echo "✗ FAIL"

# 2. Verificar OmniRoute accesible
echo "2. OmniRoute reachable..."
docker exec api-llm-gateway wget -q -O- http://omniroute:20128/ > /dev/null && echo "✓" || echo "✗ FAIL"

# 3. Chat completion via OmniRoute
echo "3. Chat completion..."
RESPONSE=$(curl -s -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"responde OK"}],"max_tokens":10}')

echo "$RESPONSE" | grep -q "\"content\"" && echo "✓" || (echo "✗ FAIL"; echo "$RESPONSE")

# 4. Verificar logs
echo "4. Logs contain routing info..."
docker logs api-llm-gateway | grep -q "omniroute" && echo "✓" || echo "✗ WARN"

echo "=== Done ==="
```

### Ejecución
```bash
chmod +x test-omniroute.sh
./test-omniroute.sh
```

## Criterio Pase
- ✓ HTTP 200 desde handler
- ✓ Response tiene content no vacío
- ✓ Logs muestran omniroute fue elegido
- ✓ Latencia < 2s

## Troubleshooting

| Error | Causa | Fix |
|---|---|---|
| "sin adapter para omniroute" | No registrado en buildAdapters() | Ver HU-054 |
| Connection refused | OmniRoute no corriendo | `docker-compose -f docker-compose.omniroute.yml up -d` |
| 503 Service unavailable | OmniRoute responde error | `docker logs omniroute-provider` |
| 500 Internal error | Bug en adaptador | Ver logs + HU-051 |
